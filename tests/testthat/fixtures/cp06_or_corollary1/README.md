These are independent input goldens, not expectations generated by the R backend.

`raw.csv` is a byte copy of the supplied 144-identity finite table. `F_rows.csv`,
`B_rows.csv`, and `A_rows.csv` are byte copies of the supplied independent NumPy
reference rows, in the original raw-table order (ID 1 through 144). Columns are
four cohort a IFs; eight pair-major/cohort-major two-coordinate alpha IFs;
four two-coordinate regression IFs; six link IFs; tau, eta, and lambda.

Regressions, in order: (1,2)/{6,NT}, (2,4)/{6,NT}, (1,2)/{NT}, (2,4)/{NT}.
Links, in order: g3/reg1, g4/reg1, g3/reg2, g4/reg2, g3/reg3, g4/reg4.
The outcome and selection designs for these goldens are (1,x).

`points.csv` and `transport.csv` are lossless CSV translations of supplied JSON
reference points and frozen known transport values, respectively. NT means Inf.
Transport is looked up by route/cohort/x and held fixed, including during any
case-weight perturbation. Selection uses the U denominator, without rho.

`SOURCE_PINS.json` pins the original sources; it is provenance only and is not
read by the R tests. The fixture preparation script is saved in scripts/.
Tests use testthat::test_path and base CSV readers only. This is finite algebra
evidence, without claims about DGP validity, coverage, or a public pipeline.
